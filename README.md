# Sistema Bancario - Git Flow

## Descripción

Este proyecto corresponde al desarrollo de un Sistema Bancario utilizando PHP y aplicando la metodología Git Flow para el control de versiones.

## Funcionalidades

- Registro de clientes
- Creación de cuentas
- Consulta de saldo
- Consignaciones
- Retiros
- Transferencias

## Tecnologías

- PHP
- Git
- GitHub
